# CobbleSynergy 0.3.2

CobbleLeague 0.7.6 / Minecraft 1.21.1 / Cobblemon 1.7.3용 타입 시너지 애드온입니다. 던전 임시 파티의 타입을 계산하고 전투 효과와 HUD·U 도감을 제공합니다. 효과는 서버가 적용하며 화면 표시는 클라이언트 애드온을 사용합니다.

## 0.3.2 변경점

CobbleLeague 0.7.6의 GitHub 자산 API 기반 전송 보완과 함께 배포하는 호환 메타데이터 갱신입니다. 시너지 실행 코드는 유지합니다.

## 0.3.1 변경점

CobbleLeague 0.7.5의 4라운드 간격 관장전·후반 챔피언·공통 HP 차감·테라피스 상점과 함께 배포하는 호환 조합입니다. 시너지 효과와 관전 연동 방식은 유지합니다.

## 0.3.0 변경점

### 관전

관전 권한·실제 이동·위치 복귀·전투 종료 처리는 CobbleLeague의 공개 API가 관리합니다. F4의 경기 관전 또는 `/synergy watch`에서 진행 중인 경기를 선택합니다.

- 같은 던전 참가자 중 자기 전투가 없는 사람만 관전할 수 있습니다.
- 2인 관장전에서도 먼저 끝낸 참가자가 아직 싸우는 참가자의 방으로 이동해 관전합니다.
- 관전 종료·대상 경기 종료·다음 라운드·본인 경기 시작 때 원래 위치로 돌아갑니다.
- 게임 모드를 변경하지 않으며 관전자가 전투에 참가하거나 도구를 소모하지 않습니다.

### 페어리: 요정의 장막

| 페어리 수 | 상대 기술 명중률 | 지속 | 추가 효과 |
|---|---|---|---|
| 2 | 원래 판정 ×0.95 | 3턴 | — |
| 4 | 원래 판정 ×0.92 | 3턴 | 미스트필드 3턴 |
| 6 | 원래 판정 ×0.90 | 4턴 | 미스트필드 5턴 |

해당 진영을 겨냥한 상대 기술에만 적용합니다. 필중기·일격기와 같은 편의 기술에는 적용하지 않으며, 중복 계산으로 10%를 초과해 줄이지 않습니다. 미스트필드의 접지·상태이상 방지·드래곤 피해 감소는 원래 전투 규칙을 따릅니다.

기존 페어리의 확률 강화·추가 구매·리롤 혜택은 제거했습니다. 설정 설계 버전 3을 4로 올릴 때 이전 파일을 백업하고 **페어리 정의만 교체**해 다른 타입의 사용자 수치와 상한을 보존합니다.

## 플레이어 설치와 자동 업데이트

[코블리그 통합 릴리스](https://github.com/arscabar/CobbleLeague/releases)의 친구용 ZIP으로 두 애드온과 업데이트 보조 파일을 함께 설치합니다. **업데이터는 하나**이며, 코블리그와 시너지의 호환 버전을 함께 관리합니다.

처음 설치한 이후 Modrinth의 Play로 게임을 켜면 메인 메뉴에서 통합 안정 릴리스를 확인합니다. 업데이트가 있으면 정상 종료 → 검증·백업 → 두 모드 교체 → 동일 Modrinth 프로필 재실행 순서로 동작합니다. 서버는 배포한 조합의 최신 버전을 설치해 둔 것으로 가정합니다. 이 저장소의 단독 소스 커밋만으로 플레이어에게 배포되지는 않으며, 통합 릴리스에 반영해야 합니다.

U는 도감, F4의 시너지 버튼은 현황, F4 경기 관전은 관전 대상을 고르는 창입니다. HUD 위치와 표시 방식은 U 화면에서 조정합니다.

## 서버

서버와 클라이언트에 같은 배포 조합을 설치합니다. 설정은 `config/cobblesynergy/synergies.json`, 켜기·끄기는 `config/cobblesynergy/state.json` 또는 `/synergy on`, `/synergy off`입니다. 던전 밖 일반 전투·대여전·덱 지정전에는 시너지를 적용하지 않습니다. 관장전은 플레이어 쪽 시너지를 사용합니다.

## 빌드와 검증

JDK 21과 Gradle이 필요합니다. CobbleLeague 0.7.6 배포 JAR을 `libs/cobbleleague-0.7.6.jar`에 두거나 `-Pcobbleleague_jar=절대경로`로 지정합니다. 기본값 `test_build=false`가 일반 배포이며, 테스트 빌드는 별도로 `-Ptest_build=true`를 지정합니다.

```powershell
gradle --no-daemon test build
node test/sim/synergy-sim.js "<Cobblemon Showdown 폴더>" build build/sim-result.log
node test/sim/fairy-accuracy.js "<Cobblemon Showdown 폴더>" build
python tools/package_release.py
```

검사에는 18종 설정·설명, 이전 설정 보존, 실제 Showdown 효과와 지속 시간, 페어리의 명중 판정·필중기·일격기 제외·중첩 상한이 포함됩니다. 로컬 검증 결과와 실제 Modrinth 재실행 결과는 `VALIDATION.md`에 정리합니다.
