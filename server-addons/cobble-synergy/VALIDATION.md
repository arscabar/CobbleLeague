# 0.7.4 / CobbleSynergy 0.3.0 검증

- Core JUnit 103개, Synergy JUnit 8개 통과. 기존 연습장 57개·기록 모듈 79개 검사 결과도 유지합니다.
- 실제 Cobblemon 시험 서버 검사 104개 통과: 선택 보상, PvP 양측 동의 재시작, 해당 관장전만 재시작, 장비 교환·전체 해제·중복 생성 방지, 2인 관장전 실제 관전 TP·복귀·자동 복귀·파티 보존 포함.
- 실제 Showdown 시너지 검사 343개와 페어리 명중률·지속 시간·필중기·일격기 제외·중첩 상한 검사 32개 통과.
- 두 모드 자동 업데이터 검사 8개, 기존 설치기 검사 6개 통과. 해시·버전 조합 오류, 부분 업데이트 방지, 복구, 다운그레이드 방지를 확인했습니다.

## Modrinth 실제 재실행

설치한 실행 코드와 같은 코드를 가진 검증용 버전 표기(0.7.4-rc1 / 0.3.0-rc1)에서 검증 배포 파일(0.7.4 / 0.3.0)로 전환했습니다. 이 시험은 로컬 검증 배포 파일을 사용했으며, GitHub 다운로드 전송 경로와 구분합니다.

실제 Modrinth 실행 경로에서 게임 시작 → 메인 메뉴의 업데이트 감지 → 업데이터 인계 → 정상 종료 로그 → 두 모드 교체 → Modrinth의 동일 고유 프로필 ID로 재실행을 확인했습니다. 재실행된 실제 코블버스 메인 화면과 안정 버전 두 모드 로딩을 확인했습니다. 검증 후 로컬 검증 설정을 해제했으며, 설치 전 복구 기록도 일반 설치 기준으로 복원했습니다.

Modrinth 0.22.0에서 고유 인스턴스 ID를 사용하는 실행 링크가 동작하는 것을 확인했습니다. 일반 Play와 실행 링크는 같은 게임 초기화 및 메인 메뉴 업데이트 확인 코드를 사용합니다. 새 버전이 없으면 재실행하지 않습니다.

## 범위

관전 카메라의 모든 그래픽 배치와 3~8인 전체 조합을 화면으로 검증한 것은 아닙니다. 서버 이동·관전 등록·복귀는 실제 2인 관장전으로, 기존 PvP와 참가자 제한은 시험 서버로 검사했습니다. 운영 서버는 수정본을 설치하고 꺼둔 상태로 유지합니다.
