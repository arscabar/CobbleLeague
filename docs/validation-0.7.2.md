- CobbleLeague / 연습장 / 배틀 기록 모듈 빌드 성공, JUnit 233개 통과 (각각 97 / 57 / 79).

- PvP와 PvE의 양쪽 활성 포켓몬을 강제로 제거한 뒤 같은 HP·식별자·소유자로 복구하는 검사 통과.

- 애니메이션 대기와 관계없이 항복 시 전투 등록이 즉시 해제되는 검사 통과.

- 상점 44종 전부 시험 서버의 실제 아이템 등록 확인.
- 친구용 설치·재설치·복구·호환성·손상 파일 거부 등 설치 검사 6개 통과.

실제 렌더링 클라이언트 화면을 이 검사로 확인한 것은 아닙니다. 사용자 환경에서 최초 개체 소실 또는 소환 실패를 일으킨 원인은 과거 로그만으로 확정하지 않았습니다. 새 진단 로그는 정체 시점의 전투·포켓몬·개체·빔 상태를 기록합니다. 엔진의 입력이나 턴 대기를 무조건 통과시키지 않습니다.
