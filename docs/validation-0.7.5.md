# 0.7.5 검증

- 본체 JUnit 105개, 시너지 호환 모듈 8개 통과.
- 실제 Cobblemon 시험 서버에서 4·8·12·16·20라운드를 각각 생성해 실제 AI 행동을 진행하고 결과를 고정한 21개 검사 통과.
- 15개 트레이너 프리셋의 레지스트리·팀 크기를 검증했고, 실제 마일스톤 전투에서 4라운드 4마리·나머지 6마리·모두 레벨 50을 확인했습니다.
- 관장전에도 단계별 패배 HP 차감 1·2·3·4·5가 적용됩니다. 이후 라운드와 차감 증가·현재 최대치에 대한 모델 회귀 검사를 포함합니다.
- 테라피스 3골드 차감과 실제 임시 포켓몬 테라타입 변경, 같은 타입·잘못된 타입의 미차감, 전투 후 유지, 던전 종료 후 원래 파티 및 테라타입 보존을 확인했습니다.
- 두 모드 업데이터 8개와 기존 설치기 6개 검사 통과. 자동 재실행 코드는 0.7.4에서 실제 Modrinth 동일 프로필 재실행을 확인한 코드를 유지합니다.

관장·챔피언 난이도 구분은 이 던전의 테마 파티 설계이며 공식 캐릭터 강함 순위는 아닙니다. 그래픽 화면에서 모든 신규 관장의 스킨·배치를 따로 검증한 것은 아닙니다. 운영 서버의 기존 maxLossDamage=3은 15로 갱신해 12라운드 이후에도 차감이 증가하도록 적용합니다.
