# 0.7.3 검증 기록

- 본체 JUnit 102개 통과(총 세 모듈 누적 238개). 보상 단일 지급, 잘못된 토큰·중복 요청, 실패 후 재시도, 돈 고정 + 서로 다른 무작위 2종, 시도별 PvP 동의 및 라운드 미정산을 검사했습니다.
- 별도 COBBLEVERSE 시험 서버의 실제 전투 흐름 검사 96개 모두 통과.
- PvP에서 첫 동의만으로는 재시작하지 않고, 두 번째 동의로 새 전투를 생성하는지 확인. 이전 전투 ID의 재시작 요청을 거부하고 HP·돈·라운드를 유지하는지 확인.
- 동시 관장전에서 요청자 전투만 새 전투 ID로 교체하고, 다른 참가자의 전투 객체·진행 상태가 그대로 유지되는지 확인. 관장·HP·돈·라운드 미정산 확인.
- 승리 직후 보상 일괄 미지급, 돈 포함 3개 후보, 선택 전 확인 완료 거부, 선택한 종류만 지급, 중복 수령 거부를 확인.
- 무작위 제시 자체와 별도로 환상·전설의 특정 지급 경로를 테스트할 때는 시험용 후보를 고정했습니다.
- 친구용 설치 검사 6개 통과. 기존 다른 모드·설정·월드를 보존하는 설치·복구를 확인했습니다.

실제 렌더링 게임 화면은 이 검사 범위에 포함되지 않습니다. 마지막 클라이언트 전용 F4 접근 수정 후에도 배포 JAR의 모든 서버 측 파일이 실제 전투 시험에 사용한 JAR과 같은지 비교했습니다. 실패한 재시작은 해당 대전만 대기 상태로 남기며, 다른 전투를 종료하거나 승패·보상으로 정산하지 않습니다.
