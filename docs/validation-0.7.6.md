# 0.7.6 배포 전송 경로 보완

0.7.5의 관장전·HP 차감·테라피스 기능은 유지하고 GitHub 자산 다운로드 전송 경로만 보완했습니다. 일반 /releases/download/ 경로의 504 오류를 확인했고, 공식 /repos/.../releases/assets/... API와 application/octet-stream 요청은 정상 동작하는 것을 확인했습니다.

- 본체 JUnit 105개, 시너지 호환 모듈 8개 통과.
- 게임에 사용하는 실제 Zulu JRE 21에서 자산 API로 배포 JSON을 내려받는 검사 HTTP 200 통과.
- 실제 GitHub의 두 모드를 API로 내려받고 검증·설치하는 업데이터 실행 성공.
- 로컬 업데이터 검사 8개 통과.
- 서버 기능 클래스·리소스는 버전 메타데이터를 제외하고 관장전/테라피스 실전 검사 21개를 통과한 0.7.5와 동일함을 비교했습니다. 플레이어의 원래 파티 보존과 4·8·12·16·20라운드 실제 AI 진행/점수 정산은 그 검사에 포함됩니다.

외부 Gradle 배포 서버 장애로 GitHub Actions 빌드가 실패하여 검증한 로컬 빌드로 릴리스를 게시합니다. 다운로드 대기 시간 보완은 master에 반영했습니다.
